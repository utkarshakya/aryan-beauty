# Legacy Application

This directory contains the original implementation of AryanBeautyParlour.

- `client/` — React + Vite frontend
- `server/` — Express API with MongoDB/Mongoose and related services

The active application is now the Next.js application at the repository root.

## Rules

- Treat everything in this directory as reference-only.
- Do not extend the legacy architecture for new product development.
- Reuse useful product behavior, business rules, UI ideas, or assets when appropriate, but implement them in the new architecture.
- Keep this directory isolated from the active application.
