# Ideas

This is the backlog for possibilities that are not part of the active high-level plan yet.

Ideas are not commitments. Promote an idea into `product.md` only when there is a reason to build it.

## Product Ideas

- Multi-salon / multi-branch support
- Voice AI booking
- Advanced analytics
- Customer re-engagement
- No-show prediction
- More intelligent service recommendations
- AI business copilot
- Other features discovered from real salon usage

## AI Exploration

Potential learning areas:

- Prompt engineering
- Structured outputs
- Tool/function calling
- Retrieval and RAG
- Agents and workflows
- Evaluation
- Automation
- Prediction / basic ML

## Rules

- Keep ideas lightweight.
- Do not turn the backlog into a second roadmap.
- Real user problems should usually outrank interesting technology.
- When an idea becomes an active commitment, move it into `product.md` or add
  it to the active checklist in `plans/plan.md`.
