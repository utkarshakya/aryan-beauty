# Plans

- Active work plans live in `docs/plans/` as one file per plan.
- Never link to or mention a plan from any other document (README, `product.md`, `ideas.md`, `architecture.md`, docs index). Plans are working scratchpads, not permanent documentation.
- When a plan is complete, delete the file entirely — even if it still has unchecked leftovers. Git history is the archive; do not keep the plan around "for reference".
- Start new work by writing a fresh plan, not by resurrecting a deleted one.
